How it works

One Mac at home does the work. Every other device is a window onto it.

1

Install the server on your Mac

A menu-bar app that keeps Claude Code and Codex sessions alive, even when the lid is closed. Your API keys and logins never leave that Mac.

2

Pair your devices

Scan a code once. Each device gets its own key; the connection is end-to-end encrypted and goes straight to your Mac, with a relay only when a direct path is impossible.

3

Work from anywhere

Start a chat in any project folder, switch models, answer the agent's questions, approve edits and commands, or drop into a real terminal.

Everything the desktop apps do. On the device you have.

Built for people who already live in Claude Code and Codex.

Claude Code

Full sessions, resumable

Thinking, tool calls, diffs and plans rendered properly. Pick up any past session from the Mac's history and keep going.

Codex

Same app, same flow

Approval policy and sandbox per chat, model and effort switching, questions answered in place.

Terminal

A real terminal, not a preview

Open any tmux window as a live terminal with a proper keyboard bar. Sessions survive your phone sleeping.

Approvals

Say yes from the couch

Commands and file changes wait for you with the diff attached. Allow once, allow for the session, or flip auto-allow for a chat you trust.

Push

Know when it's done

A reply ready or an approval needed pings your phone, with a deep link straight into that chat.

Organised

Projects, archive, search

Sessions grouped by agent and project folder, archive what you're done with, instant reopen from local cache.

Private by design

There is no Chill cloud in the middle. The agents, the code, the transcripts and the API keys all stay on your Mac.

Traffic between your devices is end-to-end encrypted with per-device keys. Relays, when needed, only forward ciphertext and step aside as soon as a direct connection is up.

  • No account to create
  • No transcript ever uploaded to us
  • Open protocol, open gateway source
  • Works with your existing Claude and Codex logins
