Getting help

  • Bug or question? Open an issue: github.com/Jian130/ai-studio/issues
  • Setup help (pairing, Chill Server install, the claude/codex CLI prerequisites): see the README and the in-app pairing flow — scanning the QR code from Chill Server is the whole setup, no accounts or extra configuration needed.

Common issues

"Not running" / can't pair — Chill Server needs to be running on the Mac first (menu bar icon). Open it, click "Pair a device…", and scan the code with the phone's camera.

Claude / Codex shows as not found — Chill Server detects whether the claude and codex CLIs are installed and signed in on that Mac; install and sign into whichever one you plan to use from a Terminal on that Mac, then reopen Chill Server.

Unlock didn't carry over to a Mac — the purchase syncs to a Mac automatically the next time your phone connects to it. If it hasn't shown up, try reconnecting (pull to refresh, or reopen the chat list) once your phone has a normal internet connection.
